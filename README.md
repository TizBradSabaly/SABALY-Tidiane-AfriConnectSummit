## Technologies utilisées
- HTML5 (structure sémantique, accessibilité)
- CSS3 (Flexbox, Grid, variables CSS, animations, responsive design)
- JavaScript vanilla (manipulation du DOM, événements, IntersectionObserver, localStorage)
- Git & GitHub (versioning, déploiement GitHub Pages)

## Fonctionnalités JavaScript implémentées
- [x] Dark mode / Light mode avec sauvegarde dans localStorage
- [x] Navbar dynamique (changement de fond au scroll) + menu hamburger mobile
- [x] Animations au scroll (IntersectionObserver) : fade-in, slide-in, zoom-in
- [x] Onglets du programme (Jour 1 / Jour 2 / Jour 3)
- [x] Filtrage dynamique des intervenants par thématique
- [x] Compte à rebours en temps réel jusqu'à la date de la conférence
- [x] Compteurs animés (statistiques qui s'incrémentent au scroll)
- [x] Validation complète du formulaire d'inscription (regex email, téléphone, longueur du message, retours visuels par champ, message de succès, réinitialisation)
- [x] Bouton retour en haut (apparition au scroll, défilement fluide)
- [x] Année dynamique dans le footer
